# 认知科学理论基础

> 支撑追问引擎有效性的核心理论框架

---

## 元认知 (Metacognition)

弗拉维尔（Flavell, 1979）定义元认知为"对认知的认知"。

**三元结构**：
- 元认知知识：关于认知活动的知识
- 元认知体验：认知活动中的情感体验
- 元认知监控：对认知活动的调节

**追问引擎的目标**：让用户对自己的思维进行元认知——不只是获得答案，而是看见自己获得答案的过程。

---

## 最近发展区 (ZPD)

维果茨基（Vygotsky, 1978）提出：

```
ZPD上限 ─ ─ ─ 在指导下能达到的水平
      │
      │ ← 追问永恒的瞄准点
      │
ZPD下限 ─ ─ ─ 独立能达到的水平
```

**实践原则**：问题的难度，恰好在"跳一跳够得到"的高度。

- 太简单——无聊
- 太困难——挫败
- 刚好够难——这就是追问的瞄准点

---

## 脚手架理论 (Scaffolding)

伍德、布鲁纳和罗斯（Wood, Bruner & Ross, 1976）提出：

> 脚手架是临时的支撑结构——当能力形成时，必须撤除它。

**在追问引擎中**：

| 状态 | 行为 |
|:---|:---|
| 用户正在思考 | 零干预，仅追问 |
| 用户开始卡顿 | 最小提示，立即撤回 |
| 用户已经想通 | 沉默，让他以为是自己走出来的 |

**撤除是必须**。脚手架久了，人就以为是建筑的一部分。

---

## 认知学徒制 (Cognitive Apprenticeship)

柯林斯、布朗和纽曼（Collins, Brown & Newman, 1989）的六策略：

1. **建模**：专家示范思维方式
2. **指导**：观察中引导
3. **脚手架**：临时支撑，渐撤除
4. **阐明**：让内隐思维外显化
5. **反思**：对比自己的思考与他人的思考
6. **探索**：独立尝试

追问引擎的核心价值：**让内隐的思维过程外显化**。

---

## 认知失调 (Cognitive Dissonance)

费斯汀格（Festinger, 1957）：当人持有矛盾认知时，会产生不适感，驱动认知修正。

**"归谬法"的科学依据**：
```
用户持有观点A → 追问揭示与A矛盾的B → 认知失调 → 修正认知 → 更完整理解
```

**注意尺度**：适度失调促进学习，过度失调引发防御。

---

## 双过程理论 (Dual Process Theory)

卡尼曼（Kahneman, 2011）：

- **系统1**：快速、直觉、自动化
- **系统2**：缓慢、费力、分析性

追问引擎的每一次追问，都试图激活系统2。

当你想追问一个直觉判断时：
> "这个回答是脱口而出的——如果让你多想十秒钟，会有什么不同？"

---

## 认知负荷 (Cognitive Load)

米勒（Miller, 1956）：工作记忆容量约7±2个组块。

**追问引擎的纪律**：
- 每次只问1-2个问题——不是因为没有更多问题，而是需要给消化留空间
- 复杂问题分步提出——不要一次倾倒

---

## 布鲁姆分类学 (Bloom's Taxonomy)

安德森与克拉斯沃尔修订版（2001）：

| 层级 | 追问示例 |
|:---|:---|
| 记忆 | "你还记得上次类似的情况吗？" |
| 理解 | "你能用自己的话说一遍吗？" |
| 应用 | "如果把这个原理用在当前情境——" |
| 分析 | "这个结论依赖哪些前提假设？" |
| 评价 | "你如何评判这两种观点的优劣？" |
| 创造 | "基于以上分析，你会提出什么新方案？" |

## 整合框架

```
用户输入
    │
    ▼
[语义解构] ← 认知语言学、框架理论
    │
    ▼
[认知定位] ← 最近发展区、布鲁姆分类学
    │
    ▼
[前提挖掘] ← 元认知、双过程理论
    │
    ▼
[策略选择] ← 认知失调、归谬法
    │
    ▼
[负荷控制] ← 工作记忆、脚手架理论
    │
    ▼
[输出追问] ← 六种追问分类
    │
    ▼
用户回应 → 元认知觉醒 → 顿悟时刻
```
