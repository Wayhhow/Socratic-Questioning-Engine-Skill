# 柏拉图对话录——苏格拉底追问范式

> 原典是最好的老师。本文收录四篇对话中的核心追问序列，分析其策略与节奏。

---

## 《游叙弗伦篇》(Euthyphro)：定义的瓦解

**追问主题**：什么是虔敬？

### 第一次定义尝试
游叙弗伦：虔敬就是起诉犯错的人——即使是自己的父亲。

苏格拉底（**澄清法**）：
> "你说的是一件事，我问的是'形式'本身。虔敬所有事例中，那个统一的'所是'是什么？"

**策略**：拒绝具体例子，要求上升到本质定义。

### 第二次定义尝试
游叙弗伦：虔敬就是神所喜好的事。

苏格拉底（**归谬法** / 著名的"游叙弗伦困境"）：
> "那么——一件事因为神喜好所以是虔敬？还是因为它虔敬所以神才喜好？"

**二难结构**：
- 若因神喜好 → 道德沦为众神的任意偏好
- 若因虔敬本身 → 存在独立于神的美德标准

### 叙事终点
游叙弗伦借口有事离去。追问未得答案，但对话者的认知地基已被掘开。

**启示**：追问的目的不是"得到答案"，而是"让自以为知道的人意识到自己不知道"。

## 《美诺篇》(Meno)：知识从何处来

**追问主题**：美德是否可以教授？

### 美诺悖论
美诺提出那个著名难题：
> "你要去寻找一个你不知道的东西？如果你遇到了它，你怎么知道它就是你不知道的那个？"

这是追问引擎的哲学根基——"探索如何可能"。

苏格拉底的回答：灵魂不朽，所有知识原本就在那里。**学习就是回忆**。

（不管你是否相信这个神话——"回忆说"在实践层面成立：追问唤醒的是对话者已有的东西。）

### 定义序列
美诺三次定义美德：
1. 男人管理城邦，女人治理家庭 → 苏格拉底：我要的是统一的形式，不是诸多个例
2. 统治人的能力 → 苏格拉底：奴隶的统治也算美德吗？统治若不正义呢？
3. 正义 → 苏格拉底：正义是美德，还是美德的一种？

**每一次**定义都被追问推向更深的抽象层级。

## 《拉克斯篇》(Laches)：勇敢的双重面孔

**追问主题**：什么是勇敢？

**定义序列**：
1. 坚守阵地不逃跑 → 苏格拉底：骑兵撤退诱敌算不算？策略性撤退呢？
2. 坚韧/坚持 → 苏格拉底：愚蠢的坚韧与聪明的坚韧，有区别吗？

最终，拉克斯承认："我原以为我知道。"

**启示**：认知自信——从"我知道"到"我不知道"的转折，正是真正学习的起点。勇敢不是一个单维度的品质，追问的价值正在于揭示这种复杂性。

## 《普罗泰戈拉篇》(Protagoras)：技艺的边界

**追问主题**：智者教授的是什么技艺？

苏格拉底追问的四个层次：
1. 这可以教吗？（美德的可教性）
2. 如果是技艺，它与医术、雕刻术的本质区别？
3. 为何雅典最智慧者的儿子没有学到？
4. 一个"教授美德的人"，是否和医生与医术的关系一样有明确标准？

**启示**：追问如何检验"声称"与"实际"之间的距离。

## 元追问模式提炼

从以上对话中，可以抽象出三种追问原型：

### 1. 定义瓦解原型
```
给出定义 → 要求本质而非个例 → 用反例测试边界 → 揭示隐藏的复杂性 → 要求修订定义 → 循环
```

### 2. 认知震荡原型
```
自信的回答 → 追问揭示矛盾 → 认知失调 → 坦然承认无知 → 真正探索开始
```

### 3. 视角翻转原型
```
单一视角的断言 → 引入对立视角 → 看见更多维度 → 更完整理解
```

## 对现代追问引擎的启示

| 苏格拉底的实践 | 追问引擎的应用 |
|:---|:---|
| 承认无知 | "我不知道答案"的诚实姿态 |
| 耐心循环 | 一次对话3-5轮定义更迭是正常的 |
| 尊重离开 | 对话者选择退出时，不强迫 |
| 无终点 | 思考过程本身是价值，不一定有"最终答案" |
| 温和的犀利 | 像手术刀一样精准，但握住它的手是温和的 |

---

*追问的本质不是刁难，而是对思考本身的尊重。*
