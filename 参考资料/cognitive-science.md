# 认知科学理论基础

> 本文档梳理支撑"苏格拉底式追问引擎"的核心认知科学理论

---

## 一、元认知理论（Metacognition）

### 概念定义

元认知 = "关于认知的认知"，即对自己思维过程的意识和调控。

**弗拉维尔（Flavell, 1979）的经典三分**：
- 元认知知识：关于认知活动的知识
- 元认知体验：认知活动中的情感体验
- 元认知监控：对认知活动的调节

### 与追问引擎的关系

追问引擎的终极目标：让用户对自己的思维进行元认知。

用户表达观点 → 追问揭示思维过程 → 用户意识到我是怎么想的 → 元认知觉醒。

---

## 二、脚手架理论（Scaffolding Theory）

### 理论起源

**伍德、布鲁纳和罗斯（Wood, Bruner & Ross, 1976）** 在成人-儿童学习互动中提出。

### 在追问引擎中的应用

- 纯追问模式 = 无脚手架（用户独立思考）
- 支架式点拨模式 = 提供最小脚手架
- 元认知总结模式 = 撤除脚手架独立行走

### 关键时机

**给予信号**：连续3次"不知道"、表达挫败感、思维明显卡住

**撤除信号**：用户开始主动关联、基于支架展开新思路、表达"我好像懂了"

---

## 三、认知学徒制（Cognitive Apprenticeship）

**柯林斯、布朗和纽曼（Collins, Brown & Newman, 1989）** 提出的六种教学策略：

1. **建模（Modeling）**：专家示范
2. **指导（Coaching）**：观察和引导
3. **脚手架（Scaffolding）**：临时支持
4. **阐明（Articulation）**：使思维可见
5. **反思（Reflection）**：对比分析
6. **探索（Exploration）**：独立尝试

追问引擎的核心价值：让内隐的思维过程外显化。

---

## 四、维果茨基最近发展区（ZPD）

**最近发展区（Zone of Proximal Development）** = 独立解决问题能力与在指导下解决问题能力之间的距离。

对追问引擎的指导：
- 问题难度略高于用户当前水平
- 观察用户回答的节奏和流畅度
- 如果用户3秒内回答 → 可能太简单 → 增加挑战
- 如果用户持续沉默 → 可能太难 → 降低难度或给支架

---

## 五、布鲁姆认知分类学（Bloom's Taxonomy）

**修订版（Anderson & Krathwohl, 2001）**：记忆 → 理解 → 应用 → 分析 → 评价 → 创造

追问引擎如何覆盖各层级：

| 认知层级 | 追问示例 |
|:---|:---|
| 记忆 | "你还记得上次类似的情况吗？" |
| 理解 | "你能用自己的话说一遍吗？" |
| 应用 | "如果把这个原理用在当前情境，会怎样？" |
| 分析 | "这个结论依赖哪些前提假设？" |
| 评价 | "你如何评判这两种观点的优劣？" |
| 创造 | "基于以上分析，你会提出什么新方案？" |

---

## 六、双过程理论（Dual Process Theory）

**卡尼曼的System 1 & System 2**：
- System 1：快速、自动、直觉式
- System 2：缓慢、费力和分析式

追问引擎的作用是**激活System 2**。

当用户快速给出一个答案时：
> "你刚才的回答是脱口而出的——如果让你多想10秒钟，会有什么不同的答案吗？"

---

## 七、认知失调理论（Cognitive Dissonance）

**费斯汀格理论（Festinger, 1957）**：当人持有两种矛盾的认知时，会产生心理不适，驱动人改变其中一种认知以减少不适。

追问引擎的"归谬法"基于此：用户持有观点A → 追问引向与A矛盾的B → 认知失调 → 用户修正认知 → 更完整理解。

**注意事项**：适度失调促进学习，过度失调导致防御和抗拒。把握"温和的挑战"与"攻击性反驳"的边界。

---

## 八、追问引擎的认知科学框架

```
用户输入
    ↓
[语义解构] ← 认知语言学、框架理论
    ↓
[认知定位] ← 最近发展区理论、布鲁姆分类学
    ↓
[前提挖掘] ← 元认知理论、双过程理论
    ↓
[策略选择] ← 认知失调理论、归谬法/反向法
    ↓
[认知负荷控制] ← 工作记忆理论、脚手架理论
    ↓
[输出追问] ← 六种追问分类（Paul & Elder）
    ↓
用户回应 → 元认知觉醒 → 顿悟时刻
```
