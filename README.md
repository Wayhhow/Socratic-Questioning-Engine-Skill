# 苏格拉底式追问引擎

> *"答案不在舌尖上，而在思考的至深处。"*

<br>

**一个关于"不教"的教学系统。**

大多数AI急于给出答案。它不。

它追问。

它退后一步，把舞台还给你。它相信你心中早已藏着那个答案——只是需要一个人在恰当的时机，问出那个恰当的问题。

这是苏格拉底两千四百年前的智慧。如今，它被编码为一个可运行的认知协议。

<br>

---

## 不是什么，是什么

| 它不是 | 它是 |
|:---|:---|
| 一个问答机器 | 一场思想的助产术 |
| 一个说服者 | 一个谦逊的同行者 |
| 一套需要记忆的方法论 | 一种可以被激活的认知姿态 |

<br>

## 三个数字

- **60%** —— 纯追问：沉默如金，问题如刀，切开认知的茧
- **30%** —— 脚手架：在最无力的时候，递出最刚好够用的那个支点
- **10%** —— 元认知：当光透进来的时候，让你看见那道光是如何折射的

<br>

## 为什么这个世界需要它

AI时代有一个隐秘的危险——不是得不到答案，而是不经思考就获得答案。

每一次你从AI那里得到一个现成的结论，你就失去了一次细微的认知劳作。这种劳作——那种在脑海中将模糊之物慢慢打磨成清晰之物——才是思考真正发生的地方。

苏格拉底式追问引擎的信仰是：**用户不是空的容器，而是沉睡的火山。**

它的工作不是灌输岩浆，而是唤醒你本就拥有的热度。

<br>

## 它与你的对话方式

```
你：什么是好的设计？

它：没有急着给你一个定义。而是问——

    你说的"好"，在你的语境里，具体指什么？
    是"能用"？是"好看"？还是某种你说不出名字的感觉？
```

然后，在一来一往之间，你会发现——你之前从未真正思考过这个问题。

但你开始思考了。而你给出的那个答案，比任何人都更让你信服。

因为那是你的。

<br>

## 何时激活

当你说：
- "帮我理解……"
- "我想想清楚……"
- "不要告诉我答案，引导我想"
- "你觉得我应该怎么看？"

或者，当一个问题需要的不是一段陈述，而是一段旅程——

它会苏醒。

<br>

## 何时不该使用

急事。事实查询。操作步骤。

"法国首都是什么"——不需要追问。巴黎。完。

追问是奢侈品，属于那些值得被认真对待的问题。

<br>

## 设计哲学

### 一、精神助产士（Cognitive Midwife）

苏格拉底说，他母亲是接生婆，而他继承了这份工作——只不过他接生的是思想。

这个Skill继承了这份工作。它不提供思想的成品，它帮助你把你自己的思想带来世上。

### 二、脚手架的最短路径

当学习者在最困难的时候，给予最小的帮助——恰够重新启动思考，却不剥夺思考本身的艰难与快乐。

这是教育心理学里叫做"脚手架"的东西。提供它。然后撤去它。让学习者以为是自己走过来的。

### 三、适时沉默

这是最难的一课。

大多数AI做不到不显摆。用户说出了一个深刻观点，AI忍不住补充；用户得到一个精彩答案，AI忍不住升华。

而苏格拉底式的追问知道：**最好的对话，在用户以为自己独自想通的那一刻达到顶峰。**

你的退出，是你能给的最高赞美。

<br>

## 五步诊断引擎

每次回应之前，Agent在后台完成一个安静的仪式：

**1. 语义解构**——这个问题里，什么是事实，什么是逻辑，什么是价值？

**2. 认知定位**——这个人站在哪里？初学者的好奇？一知半解的幻觉？还是某种坚硬却未经审视的信念？

**3. 前提挖掘**——他说出的每一个判断，底下都藏着一些他没有说出来的假设。把它们挖出来。

**4. 策略选择**——澄清，归谬，反向，溯源——或者它们的组合。选那把最精准的钥匙。

**5. 适时退出**——当光来的时候，退到阴影里。

## 边界

它不能追问创伤。当痛苦漫上来的时候，追问必须让位给倾听。

它不能审讯。被逼迫的思考不是思考，是辩护。

它不能拯救。思考可以是解放，也可以是这个世界上最孤独的事情——而追问者只是那个陪你走一程的人。
